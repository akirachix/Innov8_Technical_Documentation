# Brand & Design System


## Logo

The PAWS logo represents protection, intelligence, and connection between wildlife, people, and technology.

Use the approved PAWS logo consistently across digital products and documentation.

![PAWS Logo](/paws-logo.png)

### Logo Usage

Use the approved:

- Primary logo
- Reverse logo
- Monochrome logo

Do not:

- Stretch or distort the logo.
- Change the logo proportions.
- Use unapproved colours.
- Place the logo on backgrounds where it becomes difficult to read.

# PAWS Brand Guidelines

The PAWS brand system provides the visual foundation for the web, mobile, documentation, and communication interfaces.

## Brand Identity

**PAWS — Predictive Alert & Wildlife Sentinel**

PAWS is a conservation intelligence platform designed to help teams predict and prevent human–wildlife and livestock conflict around water sources.



## Colour Palette

| Colour | Hex | Usage |
|---|---|---|
| Primary Green | `#3E7148` | Primary brand colour |
| Secondary Green | `#8BB89B` | Supporting UI elements |
| Accent Gold | `#E8A836` | Alerts and emphasis |
| Soft Cream | `#FFECBD` | Supporting backgrounds |
| Dark | `#1F1F1F` | Text and dark UI |

## Typography

The primary typeface is **Albert Sans**.

| Element | Font | Weight |
|---|---|---|
| H1 | Albert Sans | Bold |
| H2 | Albert Sans | Bold |
| H3 | Albert Sans | Semibold |
| Subtitle | Albert Sans | Medium |
| Body | Albert Sans | Regular |
| Caption | Albert Sans | Regular |

## UI Style

PAWS interfaces use:

- Rounded cards
- Clear information hierarchy
- Consistent spacing
- Simple navigation
- High-contrast status indicators
- Mobile-first layouts
- Field-ready interfaces

## Iconography

Icons should be simple, recognisable, and consistent with the PAWS interface.
