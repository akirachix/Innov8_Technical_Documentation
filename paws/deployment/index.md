# Deployment

## Environments

| Environment | Purpose |
|---|---|
| Development | Local engineering |
| Test | Automated/manual validation |
| Staging | Pre-production verification |
| Production | Live PAWS deployment |

## Deployment checklist

-  Production database ready
-  PostGIS enabled
-  Migrations applied
-  Secrets configured
-  MQTT secured
-  Backend deployed
-  Frontend deployed
-  AI model deployed
-  Gateways registered
-  Field devices registered
-  Monitoring enabled
-  Backups enabled
-  Test telemetry received
-  Test alert verified
-  Rollback procedure tested
