# Glossary

| Term | Definition |
|---|---|
| **AI** | Artificial Intelligence |
| **API** | Application Programming Interface |
| **Edge AI** | AI processing performed near the data source |
| **ESP32** | Microcontroller used in the PAWS field/gateway architecture |
| **HQ** | Headquarters |
| **LoRa** | Long-range, low-power radio communication |
| **MQTT** | Lightweight publish/subscribe messaging protocol |
| **PostGIS** | PostgreSQL extension for geographic data |
| **PostgreSQL** | Relational database used by the PAWS architecture |
| **Pride** | Social group of lions |
| **Risk level** | PAWS representation of the current conflict risk |
| **SX1262** | Semtech LoRa transceiver |
| **Telemetry** | Data transmitted from a field device |
| **Water pan** | A monitored water source |
| **Dispatch** | A recorded or initiated field response |
| **VHF** | Very High Frequency radio |
| **YOLO** | You Only Look Once, an object-detection model family |
