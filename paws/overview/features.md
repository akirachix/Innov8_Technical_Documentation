# Key Features

| Feature | Purpose |
|---|---|
| Water monitoring | Tracks water-source conditions |
| Wildlife detection | Identifies animals near monitored locations |
| Lion identification | Supports individual lion recognition |
| Health assessment | Captures visible health/body-condition indicators |
| Long-range telemetry | Transmits compact field observations |
| Spatial storage | Stores geographic observations |
| Risk analysis | Combines observations into operational risk |
| Alerts | Highlights situations requiring attention |
| Dispatch | Records field interventions |
| Historical analysis | Supports review of previous events |

The exact production feature set must be reconciled with the current implementation.
